# Security

Accountancy Master is a static site on GitHub Pages: there is no server, no login and no account, and a learner's
progress stays in their own browser. Still, if you find a way for the site to harm a learner (for example a script
injection through a shared link or a restored backup file), please tell us privately.

**Report it privately** through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**.
Please do not open a public issue for it. We will reply as soon as we can, and credit you in the fix if you wish.
